FinFit API 명세서

프론트엔드(Vue 3 + Pinia) ↔ 백엔드(Django REST Framework) 연동 규격

Base URL: http://localhost:8000/api 인증: Token Authentication Content-Type: application/json

목차

1. 인증 (Auth) 2. 유저 / 프로필 3. 팔로우 4. 투자 성향 설문 5. 주식 6. 포트폴리오 7. 커뮤니티 8. AI 채팅 9. 공통 에러 10. 데이터 모델
🔐

1. 인증 (Auth)

1-1. 회원가입
POST /auth/signup/
Request Body
필드타입필수설명
emailstring필수이메일 (unique)
nicknamestring필수닉네임 (unique, max 30)
passwordstring필수비밀번호
Request
{
  "email": "user@example.com",
  "nickname": "투자왕",
  "password": "password123"
}
Response201 Created
{
  "user": {
    "id": 1,
    "email": "user@example.com",
    "nickname": "투자왕",
    "bio": ""
  },
  "token": "9944b09199c62bcf9418ad846dd0e4bbdfc6ee4b"
}
Error400 Bad Request
{ "email": ["이미 사용 중인 이메일입니다."] }
1-2. 로그인
POST /auth/login/
Request Body
필드타입필수설명
emailstring필수이메일
passwordstring필수비밀번호
Response200 OK
{
  "user": {
    "id": 1,
    "email": "user@example.com",
    "nickname": "투자왕",
    "bio": "한 줄 소개"

}

1-3. 로그아웃
POST /auth/logout/
🔑 Authorization: Token <token>
Response200 OK
{ "detail": "로그아웃 되었습니다." }

4. 투자 성향 설문 (Survey)

4-1. 설문 문항 목록
GET/survey/questions/
총 5문항 고정. 각 문항 4지선다 (score: 1 / 3 / 6 / 8)
Response200 OK
[
  {
    "id": 1,
    "question": "최근에 투자 경험이 있으신가요?",
    "choices": [
      { "id": 1, "text": "전혀 없음",          "score": 1 },
      { "id": 2, "text": "있음 (6개월 미만)",   "score": 3 },
      { "id": 3, "text": "있음 (6개월~2년)",   "score": 6 },
      { "id": 4, "text": "있음 (2년 이상)",     "score": 8 }
    ]
  }
]
4-2. 설문 결과 제출
POST/survey/submit/
🔑 Authorization: Token <token>
Request Body
필드타입필수설명
answersarray필수5개 문항 선택 결과
answers[].question_idinteger필수문항 ID
answers[].choice_idinteger필수선택지 ID
Request
{
  "answers": [
    { "question_id": 1, "choice_id": 3 },
    { "question_id": 2, "choice_id": 7 },
    { "question_id": 3, "choice_id": 6 },
    { "question_id": 4, "choice_id": 8 },
    { "question_id": 5, "choice_id": 2 }
  ]
}
Response200 OK
{
  "risk_score": 29,
  "result_type": "적극투자형",
  "result_description": "높은 수익을 위해 어느 정도의 위험을 감수합니다."
}
점수 기준
점수 범위유형설명
5 ~ 12안정형안정성을 최우선으로 여기며 원금 보전에 집중합니다.
13 ~ 20안정추구형안정성을 추구하며 소폭의 수익을 선호합니다.
21 ~ 28위험중립형위험과 수익 사이의 균형을 추구합니다.
29 ~ 34적극투자형높은 수익을 위해 어느 정도의 위험을 감수합니다.
35 ~ 40공격투자형고위험 고수익을 추구하며 공격적으로 투자합니다.

Request Body
필드타입필수설명

{ "id": 1, "qty": 10, "buy_price": 214375, "current_price": 313000 }

DELETE/portfolio/holdings/{holding_id}/

9. 공통 에러 응답

HTTP 상태상황
400잘못된 요청 / 유효성 검사 실패
401인증 토큰 없음 또는 만료
403권한 없음 (타인의 게시글·댓글 삭제 등)
404리소스 없음
500서버 내부 오류
에러 응답 형식
{ "detail": "에러 메시지" }
// 필드 유효성 오류의 경우
{ "field_name": ["오류 설명"] }
